# ngx-seo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ngx-seo`, an Angular 21 library that merges layered SEO declarations into one resolved head and keeps the document in sync on the server and in the browser.

**Architecture:** Pure functions do the thinking: `mergeLayers` combines partial configs, `resolveHead` derives a flat list of keyed tags. A DOM-only `HeadReconciler` makes a `Document` match that list. The `Seo` service holds layers in signals, computes the resolved head, and drives the reconciler and server response from a root effect. Router integration and `injectSeo` are thin feeders of layers.

**Tech Stack:** Angular 21 (signals, zoneless), TypeScript, ng-packagr, vitest + jsdom, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-18-ngx-seo-design.md`

## Global Constraints

- Peer dependencies `@angular/core`, `@angular/common`, `@angular/platform-browser`, `@angular/router` at `^21.0.0`. No runtime dependencies.
- Library code must not import `@angular/platform-server` or Node APIs. Server behaviour uses `REQUEST` and `RESPONSE_INIT` from `@angular/core`.
- No zone.js. Tests provide `provideZonelessChangeDetection()`.
- Use `inject()`, never constructor parameter injection (tests run JIT without decorator metadata).
- pnpm only. ESM. Package name `ngx-seo`. MIT.
- Braces on every `if` / `else` / loop body.
- An SEO error never throws out of the library into a render: catch, report through `ErrorHandler`, keep the previous head.
- Head values are written with `setAttribute` / `textContent` only.
- Commits use conventional-commit prefixes and end with the session's `Co-Authored-By` trailer.

## Review Focus

1. Empty strings from a CMS (`title: ''`, `description: ''`, `image: ''`) are treated as unset: no empty tags, fallbacks still apply. Test in Task 2.
2. URL values with a non-http(s) scheme (`javascript:`, `data:`) or that cannot be parsed are dropped, not emitted and not thrown. Test in Task 3.
3. A function-valued route `seo` or `defaults` that throws skips that layer, reports the error, and navigation still completes with the remaining layers. Test in Task 7.
4. An `SeoHandle` used after its owner is destroyed (`set`, `patch`, `clear`) is a silent no-op. Test in Task 6.
5. An app with no `Router` provided still works: canonical derives from `document.location`, `injectSeo` applies. Test in Task 6.

### Task 2: Merge

**Files:** Create `src/lib/merge.ts`, `__tests__/merge.spec.ts`.

**Interfaces — Produces:** `mergeLayers(layers: readonly SeoConfig[]): SeoConfig`. Input is lowest priority first. Output contains no `null` and no empty strings.

- [ ] Step 1: Failing tests, one per spec merge rule:
  - scalar: `[{title:'a'},{title:'b'}]` → `title: 'b'`; `[{title:'a'},{}]` → `'a'`
  - `null` removes: `[{description:'a'},{description:null}]` → no `description`
  - empty string is unset: `[{title:'a'},{title:''}]` → `'a'`
  - objects merge per field: `[{openGraph:{title:'a',type:'article'}},{openGraph:{title:'b'}}]` → `{title:'b',type:'article'}`; nested `null` removes one field
  - raw-string `robots` replaces a lower object; object over string replaces the string
  - `jsonLd` keyed by `@id`: same id collapses to the higher layer, in the lower layer's position; nodes without `@id` are all kept
  - `alternates` keyed by `hreflang`; `meta` by `key` else `name`/`property`/`httpEquiv`; `links` by `key` else `rel|href`; `openGraph.images` by `url`
  - plain lists replace: `keywords`, `openGraph.article.tags`
  - a list set to `null` clears lower contributions; later layers can add again
  - order: keyed lists are lowest layer first; `openGraph.images` is highest layer first
  - `removeItem(key)` (`{ $remove: key }`, exported from `merge.ts`) drops the lower item with that key and never appears in the output
  - inputs are not mutated
- [ ] Step 2: Run, expect failure. Step 3: Implement. Step 4: Run, expect pass.
- [ ] Step 5: Commit `feat: merge SEO layers`.

### Task 3: URL, robots, JSON-LD serialisation, derivation

**Interfaces — Produces:**
